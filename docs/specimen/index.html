이 조합을 쓰는 이유

IBM Plex Sans KR은 같은 기준으로 측정한 수치가 Jeongdok과 가깝습니다. 영문 x-height 0.515 vs 0.532, 한글 글자 크기 0.868 vs 0.866, 세로 획(stem) 0.077 vs 0.075, 잉크 밀도 0.192 vs 0.186입니다. Display는 큰 크기에만 씁니다. Newsreader의 Display optical size는 hairline이 매우 가늘어서, 한글은 획 대비가 더 큰 마루 부리를 짝지었습니다.

조판한 한 편의 글
sharosoo · 2026.10.09 · 읽는 시간 6분 · Typography

한글과 영문이 섞인 글에서 서체를 고르는 일은 언뜻 취향처럼 보이지만, 실제로는 글자 크기, 획 두께, 세로 정렬이라는 세 가지 수치를 맞추는 작업입니다. The three numbers decide whether a mixed line reads as one voice.

코드는 따로 분리합니다. 설정은 한 줄이면 충분합니다.

const font = {
  body: 'Jeongdok',      // 본문 serif
  head: 'Jeongdok Display',
  ui:   'IBM Plex Sans KR',
  code: 'D2Koding',        // => 리가처
};

제목은 Display로 크게, 본문은 Jeongdok으로 차분하게, 라벨과 버튼은 Plex Sans로 짧게 둡니다. 한 번 고른 조합은 화면이 바뀌어도 바꾸지 않습니다.

07 · Setup

타이포그래피 설정 체크리스트

결정하기

1. 네 가지 역할(본문 · 제목 · UI · 코드)마다 서체를 하나씩 지정합니다.
2. 프로젝트 전체에 하나의 크기 체계(고정된 크기 단계)를 둡니다. 예: 14 · 16 · 18 · 22 · 28 · 36 · 48 px.
3. 줄 간격: 본문 1.7~1.8, UI 1.4~1.5, 제목 1.15~1.25, 코드 1.5.
4. 한 줄 길이: 한글 본문 28~38자, 영문 55~75자.

한글 설정

word-break: keep-all(단어 단위 줄바꿈) + overflow-wrap: break-word.
마지막 줄에 단어 하나만 남는 현상을 줄이는 text-wrap: pretty.
자간은 건드리지 않습니다(불가피할 때도 −0.01em 안쪽으로 유지합니다).

불러오기

1. 한글에는 동적 subset(unicode-range)을 씁니다.
2. font-display: swap을 적용하고, <link rel="preload" as="font" crossorigin>로 본문 서체만 미리 불러옵니다.
3. fallback 스택에 시스템 한글 서체를 두고 size-adjust로 크기 차이를 줄입니다.
4. 한 화면에는 최대 4종의 서체만 씁니다.

E Ink

가는 획은 1~2px 이상이어야 하고 획 대비가 낮아야 합니다. Display의 hairline은 큰 크기에서만 씁니다. 새 서체는 E Ink 기기에서 2-bit 화면으로 확인합니다.

새 서체 검토

① name table에 원본 Reserved Font Name 없음 ② 한글 11,172자 전체 수록 ③ 영문과 한글의 동일한 baseline ④ 한글/영문 잉크 밀도 비율 0.85~1.0 ⑤ 웹: 분할 파일이 모든 글자를 포함 ⑥ 실제 기기 렌더링 검증
